# Home24x7 Build and Repair

Marketing website for Home24x7 Build and Repair, a UK-based property maintenance and
construction company offering 24/7 responsive service for homeowners, landlords, letting
agents and commercial property managers across London and the wider UK.

## What's included

- Home, About, Services (hub + individual service pages), Compliance & Certification,
  Construction & Extensions, Areas We Cover, Gallery/Case Studies, Get a Quote, Emergency
  Call-Out, Resources/Blog, and Contact pages.
- Trust indicators (Gas Safe, NICEIC, insured, DBS-checked), testimonials, and a WhatsApp
  chat widget.
- Two lead-capture forms (quote request and contact) plus an emergency call-back form, all
  powered by Netlify Forms.

## Tech stack

- [TanStack Start](https://tanstack.com/start) with React 19 and file-based routing
  (TanStack Router)
- Tailwind CSS 4 for styling
- [lucide-react](https://lucide.dev) for icons
- Deployed on Netlify, using Netlify Forms for submissions

## Running locally

```bash
npm install
npm run dev
```

The dev server runs on `http://localhost:3000`. Note that Netlify Forms submissions only
work once deployed to Netlify — they will not succeed against the local dev server.

## Building

```bash
npm run build
```
